# Kallinos — Rise of a Mortal

A 2D RPG set in Ancient Greece, built with Python and Pygame (CE).

## Quick Start

```bash
pip install pygame-ce
python main.py
```

## Controls (current)

| Key         | Action                    |
|-------------|---------------------------|
| Up / Down   | Navigate menu             |
| Enter/Space | Select option             |
| ESC         | Back to main menu         |
